## ☕ Coffee Shop Kita

Proyek web sederhana untuk menampilkan menu andalan dari **Coffee Shop Kita**. Website ini dibuat menggunakan HTML5 dan CSS3 dasar untuk menampilkan katalog produk berupa gambar, nama menu, dan harga.

---

## 📌 Fitur Utama

- **Halaman Utama (`index.html`)**: Menampilkan daftar menu andalan lengkap dengan foto dan harga.
- **Katalog Menu**:
  - **Espresso** - Rp 20.000
  - **Latte** - Rp 25.000
  - **Americano** - Rp 25.000[cite: 6]
